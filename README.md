
# TaskFlow - Student Assignment Management System

## Project Description

TaskFlow is a student-based assignment management
web application developed for the IMS566 Individual
Project.

The system allows students to monitor their
assignments, manage task statuses and visualise
their academic progress through interactive charts.

## Features

- Hardcoded student login authentication.
- Individual student dashboard.
- Personal assignment tracking.
- Assignment progress percentages.
- Interactive assignment status management.
- Search and filter assignments.
- Assignment status visualisation.
- Progress by assignment chart.
- Classmates directory.
- Responsive navigation and website layout.

## Data Management

TaskFlow uses fixed hardcoded student and
assignment data stored in script.js.

Session Storage is used to maintain login
sessions and temporary assignment status changes.

No external database is required.

## How to Run

1. Download or clone the project repository.
2. Open the project folder in Visual Studio Code.
3. Run index.html using Live Server.
4. Login using one of the demo accounts.
5. Explore the dashboard, assignments and classmates pages.
